# Drawic 0.3.2 — Unsigned Preview

- Buttons, input fields, menus, and dialogs now follow the same light or dark theme across the editor and device library. Toolbar buttons and page tabs align, and the library filters have more space between rows.
- Moving a device preserves the gap between a Net Label and its wire. New labels appear above horizontal wires and beside vertical wires. If an older drawing already has a label on a wire, drag the label clear once to set its spacing.
- Moving a ground symbol sideways now keeps the T junction at the three-way branch, regardless of which end of the wire was drawn first.
- The Agent setup panel can copy local connection instructions in one step. The [first schematic guide](https://github.com/CanvasQAQ/drawic/blob/v0.3.2-preview/docs/first-schematic.md) walks through drawing a circuit.

## Downloads

Choose the Windows x64 ZIP, a macOS DMG or ZIP for Apple silicon (arm64) or Intel (x64), or a Linux x64 AppImage or DEB. All packages are unsigned. Windows SmartScreen and macOS Gatekeeper may prompt on first launch. Check the downloaded file against `SHA256SUMS.txt`.
