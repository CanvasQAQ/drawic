# Drawic documentation

## Use Drawic

- [Draw your first schematic](first-schematic.md). Place and connect two devices, save the project, and export a drawing.
- [Edit on the canvas](../README.md#interaction-notes). Look up selection, zoom, duplication, labels, and wire gestures.
- [Find project and recovery files](../README.md#project-files-and-local-data). Check file extensions, format compatibility, and local storage locations.
- [Connect a local Agent](LOCAL_AGENT.md). Set up a desktop MCP connection, inspect the active page, and submit an undoable edit.
- [Read the release notes](release-notes.md). Check the features and limitations documented for a specific preview.

## Understand the drawing model

- [Wire interaction model](WIRE_INTERACTION_MODEL.md). Learn when conductors connect and how wires follow devices during a move.
- [Component Name labels](COMPONENT_NAME_LABELS.md). Understand the relationship between an electrical reference and its position, appearance, and visibility on the canvas.
- [Architecture decisions](adr/README.md). Find the reasons for the project format, device library layers, editing rules, and desktop boundaries.

## Develop and maintain Drawic

- [Build and run Drawic](../README.md#development) or [preview the editor in a browser](BROWSER_PREVIEW.md).
- [Start a repository task](../AGENTS.md) and [follow the development workflow](AGENT_WORKFLOW.md) for testing, packaging, and release.
- [Audit built-in pin directions](DEVICE_PIN_AUDIT.md) or [look up grid corrections](DEVICE_GRID_REVIEW.md).
- [Review the original device library implementation plan](DEVICE_LIBRARY_PLAN.md) for its design goals, delivery phases, and acceptance scenarios.
- [Regenerate brand assets](BRAND_ASSETS.md) for the desktop app and its packages.
