# Drawic release notes

Each entry describes the unsigned preview at that version, including its
platform packages and known limitations. For features in the current source
tree, see [implemented capabilities](../README.md#implemented-capabilities).

| Preview | Highlights |
| --- | --- |
| [0.3.1](release-notes-v0.3.1-preview.md) | Place, move, rotate, or mirror devices through local MCP while keeping their connections. |
| [0.3.0](release-notes-v0.3.0-preview.md) | Style component Names and nets, switch themes, and snap device pins to wires. |
| [0.2.1](release-notes-v0.2.1-preview.md) | Move wired devices with a live preview and adjust routes using segment handles. Windows x64 ZIP preview. |
| [0.2.0](release-notes-v0.2.0.md) | Organize drawings into independent pages and place devices from a single-file catalog. |
| [0.1.1](release-notes-v0.1.1.md) | Run the Windows app from a ZIP alongside the installer and portable executable options. |
| [0.1.0](release-notes-v0.1.0.md) | First downloadable preview with schematic editing, local projects, SPICE, and diagram export. |
